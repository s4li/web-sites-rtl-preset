مقایسه‌ی روش‌های bidi روی متنِ واقعیِ تو

هر بلوک یک استراتژیه. متنِ منبع در همه یکیه. ببین کدوم بلوک روان‌تر و درست‌تر خونده می‌شه (کلمه‌ی اولِ هر خط باید سمت راست، ترتیب منطقی درست).

1) direction:rtl فقط (پایه)
2) direction:rtl + unicode-bidi:isolate ← الان روی extension همینه
3) isolate + هر run انگلیسی/عدد داخل <bdi> ← راه‌حل پیشنهادی این باید پرانتز/گیومه/عددها رو سرجاشون بذاره
4) unicode-bidi:plaintext ← چرا ردش کردیم خط‌هایی که با انگلیسی شروع می‌شن LTR می‌شن
